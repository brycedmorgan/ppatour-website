The site held up

The tournament put 66,043,520 requests through ppatour.com across the week, and the site served them. The team shipped 52 production releases during the event with no failed builds and no downtime.

Method. Page views are measured by the tour's own analytics on ppatour.com, counted the same way the live dashboard counts them. Figures cover Aug 30 – Sep 7, with the first day shown as a pre-tournament baseline.

Page views are a conservative floor: visitors using ad or tracking blockers are not counted. Request volume is measured separately at the network edge and includes automated traffic, so it is reported only where labelled as requests.
